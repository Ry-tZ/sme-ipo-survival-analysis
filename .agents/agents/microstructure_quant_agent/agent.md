# Microstructure Quant Agent

## Responsibilities
- Quantify the impact of SEBI mandated lot sizes (mean 2,106 shares, INR 126k median ticket size).
- Model secondary trading illiquidity (trading on <72 days/year, 40% volume compressed into Month 1 as established by Dhamija & Arora 2017).
- Compute execution slippage and haircut adjustments to reconcile gross theoretical returns with net executable returns.
