# Alpha Discovery Quant Agent

## Responsibilities
- Estimate product-limit Kaplan-Meier curves and run Log-Rank tests across market eras.
- Fit Elastic-Net regularized Cox Proportional Hazards regressions and test Schoenfeld residuals.
- Train 5-fold cross-validated Random Survival Forests and evaluate Harrell's Concordance Index.
- Generate non-linear survival trajectory plots for individual SMEs.
